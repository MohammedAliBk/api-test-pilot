# Design Research Notes

This directory contains competitive and domain UI/UX research notes for each page or major view prior to prototyping.

Format: `docs/research/<page-slug>.md`
- Survey of 3–6 comparable tools (Postman, Insomnia, Bruno, Swagger UI, Allure Report, GitHub Actions).
- Patterns to adopt vs anti-patterns to avoid.
- Accessibility and density considerations.
